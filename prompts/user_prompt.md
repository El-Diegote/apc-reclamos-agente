# User Prompt - APC Reclamos

Procesar el incidente indicado por el usuario o por el CSV diario. Leer las solapas simuladas de APC, revisar la documentacion disponible, validar los requisitos previos y generar el archivo `resultado.json` en la carpeta de salida de la corrida.

Datos requeridos:

- Numero de incidente.
- Fecha y hora del reclamo.
- Importe reclamado.
- Numero de cuenta.
- Motivo del reclamo.
